# PRODIGY_DS_01
## Data
The data can be found in the [wordbank website](https://data.worldbank.org/indicator/SP.POP.TOTL), containing information about the world population from the year 1960 to 2023. It has a total of 270 rows and 68 columns. 
## Exploratory Data Analysis
The data was explored through various visualizations such as bar plots which were essential in showing the population distribution such as the distribution per continent, most populated and least populated countries.
